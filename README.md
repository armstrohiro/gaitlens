# GaitLens

[起動・モデル配置の手順](web_app/README.md) · [研究者プロフィールと関連プロジェクト](https://github.com/armstrohiro)

歩行・方向転換動画の姿勢推定を試す研究用アプリです。現在公開しているのはPC上で実行するStreamlit版です。iPhone 16・iPad Pro（M4）のSafariで端末内推論を行う版は開発・実機検証前です。

動画、学習データ、学習済み重みはこのリポジトリに含みません。

研究用試作であり、診断や転倒リスク判定には使用できません。参照なし品質は未検証の独自指標で、正解率ではありません。
