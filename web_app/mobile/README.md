# GaitLens モバイル試作

Safariのブラウザ内で、固定した追加学習YOLOのONNXモデルを使って保存動画を解析する実験版です。Windowsブラウザで公開サンプルの読み込みと処理完了を確認しましたが、iPhone/iPadでの推論・速度・動画形式・メモリ・発熱は未検証です。人物選択は画像中心／前フレーム中心への近さによる仮の方法で、複数人の場合は誤選択し得ます。

本フォルダにONNX Runtime Web 1.30.0のWASM版ファイルを `vendor/` に置き、変換した `tug_all_frames_epoch5.onnx` を置いてHTTPサーバーで開きます。動画は端末からサーバーへ送られませんが、モデルと実行ライブラリはサーバーからダウンロードします。モデル重みは公開リポジトリには含まれていません。`../export_mobile.py` の変換には、研究用モデル、ONNX、ONNX Runtime、公開画像の検証用入力が必要です。

この試作は追加学習YOLOのみ対応し、動画を指定した間隔でサンプリングします。16関節の出力率、欠損数、座標CSVを表示します。標準YOLO・MediaPipe、顔モザイク、骨格動画出力は未実装です。端末内処理を正解率や臨床性能の検証と混同しないでください。
